# House Prices: Regression

This project uses the Kaggle House Prices dataset to practice preparing categorical data for machine learning.

### What I have done

* Loaded and explored `train.csv` and `test.csv`
* Checked and handled missing values
* Used **ordinal encoding** for variables with a natural order
* Used **one-hot encoding** for other categorical variables
* Split the data into training and validation sets
* Train an `XGBRegressor`
* Evaluate the model using **RMSE**
